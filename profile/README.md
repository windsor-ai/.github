Welcome to the official GitHub home of Windsor.ai, the platform that helps marketers and data teams connect, unify, and analyze all their marketing data in one place, and bring it straight into the AI tools they already use.

Windsor.ai connects 350+ data sources (Google Ads, Meta, TikTok, LinkedIn, GA4, HubSpot, Salesforce, Shopify, Stripe, and hundreds more) and delivers that data wherever you work: natively inside Claude and ChatGPT, in BI tools like Looker Studio, Power BI, and Tableau, and in your data warehouse. No code required.

Key Features:
  - 🤖 Native in Claude and ChatGPT: ask for reports in plain language and get live data back, no exports
  - 🌐 Seamless integration with major ad platforms, CRMs, and analytics tools
  - ⚡ Fast, scalable ETL pipelines with automated syncing
  - 🧩 Plug-and-play connectors for BI tools like Power BI, Tableau, and Looker Studio
  - 📊 Unified, blended marketing data models for easy analysis
  - 🔐 Enterprise-grade security and compliance

Use Cases:
  - Ask Claude or ChatGPT for blended, cross-channel performance reports
  - Build custom marketing dashboards
  - Automate data syncing to cloud data warehouses (BigQuery, Snowflake, Redshift)
  - Optimize ad spend and improve ROI visibility

Whether you are a data engineer, analyst, or marketer, Windsor.ai brings all your performance data together, effortlessly.
